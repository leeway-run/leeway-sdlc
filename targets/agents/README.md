# leeway-sdlc for agents other than Claude Code

> **OpenCode 2.x is verified; the other agents are a preview.** OpenCode was tested from a real
> OpenCode 2.2.6 session; each of the other agents' support is built in but has not been verified yet. Verified
> support for them will come later. If you run into an issue, let us know:
> https://github.com/leeway-run/leeway-sdlc/issues

Generated by `scripts/build-targets.mjs` from `plugin/`; do not edit by hand. Supported: OpenAI Codex CLI, GitHub Copilot (CLI and VS Code agent mode), Google Gemini CLI, Cursor (agent and CLI), OpenCode, xAI Grok Build.
Install with the commands in [agent-setup/prompt.md](../../agent-setup/prompt.md), then run the `sdlc-install` skill in the repo.
